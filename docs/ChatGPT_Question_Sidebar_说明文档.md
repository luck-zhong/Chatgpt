# ChatGPT Question Sidebar（Edge 扩展）说明文档

## 1. 项目概述
本扩展用于在 **Edge（Chromium）** 的 ChatGPT 页面右侧注入一个侧边栏，自动收集当前对话中的**用户提问**并提供：
- 提问列表自动更新与去重
- 点击条目滚动定位到对应提问
- 关键词搜索过滤
- 一键复制全部提问

适用域名：
- `https://chat.openai.com/*`
- `https://chatgpt.com/*`

## 3. 安装方式（Edge 开发者模式）
1. 打开 Edge，进入：`edge://extensions/`
2. 右上角开启**开发人员模式**
3. 点击 **加载解压缩的扩展**
4. 选择目录：`chatgpt-question-sidebar/`
5. 打开 ChatGPT 页面即可看到右侧“提问历史”侧边栏

---

## 4. 使用说明
- **查看提问**：侧边栏会自动抓取当前会话中的用户提问。
- **点击定位**：点击列表项自动滚动到对应提问。
- **搜索过滤**：在搜索框输入关键词筛选。
- **一键复制**：点击“复制”按钮复制全部提问内容。
- **收起/展开**：点击“收起”隐藏侧边栏，再点击右上角“提问”按钮展开。
- **刷新**：点击“刷新”强制重新扫描。

---

## 5. 技术实现说明
1. **多策略用户消息识别**
   - 优先查找 `data-message-author-role="user"`、`data-testid="user-message"`、`role="user"` 等属性。
   - 若无匹配，再进行文本长度与关键字兜底筛选。
2. **MutationObserver 监听**
   - 对 DOM 变化进行监听，实现自动更新。
3. **去重策略**
   - 使用文本 hash + 节点顺序作为稳定 key。
4. **跳转定位**
   - 为每条提问节点附加 `id`，便于点击跳转与短暂高亮。

## 6. 常见问题
### Q1：侧边栏有显示，但没有抓到提问？
可能是页面结构变化，导致选择器未命中。  
建议更新 `content.js` 中 `findUserMessageNodes()` 的选择器规则。

### Q2：列表重复或顺序变化？
如果页面启用虚拟滚动，节点序号可能变化。  
可尝试找到页面内部的 message-id 做更稳定的 key。

### Q3：点击跳转不精准？
未渲染的历史消息无法跳转，这是虚拟滚动限制。
