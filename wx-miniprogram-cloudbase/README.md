# 麻将计分小程序（本地版）

基于 PRD 的 MVP 版本，纯本地存储，无需服务器。

## 已实现

- 首页：新建牌局、继续上次牌局、历史牌局搜索/删除
- 新建牌局：2-8 人、昵称、初始分、单位、平衡记分开关
- 进行中：实时排名、最近一把变化、暂停/继续、撤销上一把、结束牌局
- 记录一把（自由加减模式）：快捷步进、手输分值、标签、备注、平衡校验
- 记录列表：按时间查看每把详情、删除记录并自动重算
- 结算页：排名、总输赢、应收应付建议、重新开启
- 持久化：杀进程后可恢复未结束牌局

## 使用

1. 用微信开发者工具导入当前目录。
2. 直接编译运行（不依赖云函数/数据库）。

## 数据说明

- 使用 `wx.setStorageSync` 保存牌局和常用玩家。
- 主数据结构见 `services/gameService.js`。
